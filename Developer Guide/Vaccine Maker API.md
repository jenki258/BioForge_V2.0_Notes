# Vaccine Maker API

#BioForge #BioForge_V0_54T #JavaAPI #JSONAPI #VaccineMaker #AddonDevelopment

JSON systems include guide profiles, Cas/PAM modules, assays, vaccine actions, correction profiles, and one Vaccine Maker recipe per file. Recipes declare inputs, evidence, quality modifiers, consumption/failure rules, and result type.

Java addons can register new operations and page factories through the public Vaccine Maker registries. All pages share the server menu inventory; custom pages must not create client-only item state or move stacks without menu packets.

Compatibility requires stable IDs, correct registration timing, JEI/Research Tablet presentation, NBT helper use, and graceful rejection of mismatched strain evidence.
