# Command Catalogue

#BioForge #BioForge_V0_54T #Command #Administration #Testing #ModpackGuide #AddonDevelopment

BioForge commands are split between normal administration, content validation, development helpers, and destructive test operations. Permission levels are enforced by the command registrations; do not expose operator-only commands to ordinary players without reviewing their effects.

## Main groups

- Infection: infect, cure, mutation control, strain management, complete infection immunity, and area decontamination.
- Blood: inspect/set/reset blood data and manage learned blood knowledge.
- Vaccine/CRISPR: manufacture controlled test outputs and inspect loaded definitions.
- Research Tablet: add, remove, add all, or remove all discovered pages for selected players.
- Definitions: reload/inspect/validate JSON-backed content.
- Tests: generate sample sets and run targeted or stress regression helpers.

See [[BioForge Command Reference]], [[Infect & Cure]], [[Blood command]], [[Blood Knowledge command]], and [[Testing and Validation]] for syntax and safety notes.
