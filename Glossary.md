# Glossary

#BioForge #BioForge_V2_0 #Wiki #Terminology

| Term | Meaning in BioForge |
|---|---|
| **Assay** | A controlled test that reveals a combined treatment result without exposing every hidden correction. |
| **Biological signature** | The stable identity used to match a sample, record, template, vaccine, immunity entry, and infection. |
| **Cas/PAM module** | The nuclease profile that controls CRISPR compatibility, PAM rules, and editing efficiency. |
| **Clinical parameter** | A typed symptom value such as oxygen saturation, heart rate, lesions, temperature state, or colony radius. |
| **Contamination** | Infection data attached to a block, item, food, drink, sample, or airborne reservoir rather than an actively infected entity. |
| **Correction matrix** | The Vaccine Maker page where observed symptoms, routes, mutations, and lifecycle information are reconstructed. |
| **CRISPR quality** | Accuracy of the 60 programmed bases across 15 cartridges and three guide roles. |
| **Cure resistance** | A lifecycle factor that reduces treatment reliability; separate from infection strength. |
| **Definition** | Reloadable namespaced data describing a pathogen, symptom, transmission, mutation, lifecycle, recipe, or research entry. |
| **Full-strain vaccine** | A treatment that attempts to cure one exact infection signature and grants temporary matching immunity on success. |
| **Incubation** | The period after infection but before normal symptom and mutation runtime becomes active. |
| **Infection strength** | The strain's competitive and clinical pressure; used when infections compete and when treatments are evaluated. |
| **Infectivity** | The lifecycle multiplier for establishment chance during exposure. |
| **Mutation** | A selectable or granted strain feature with requirements, conflicts, interactions, tags, and executable effects. |
| **Pathogen class** | Virus, bacteria, fungi, parasite, prion, or Universal. It constrains compatible content but does not uniquely identify a strain. |
| **Resistance pill** | Temporary protection against acquiring one exact strain; it does not cure an active infection. |
| **Route / transmission** | Executable spreading behavior such as air-borne, contact-based, food-borne, water-borne, attack-based, animals, blood, or environmental. |
| **Strain** | A complete infection profile with a stable signature, pathogen class, routes, symptoms, mutations, lifecycle, and optional catalogue name. |
| **Symptom suppressant** | A temporary treatment for one clinical penalty that leaves the underlying infection intact. |
| **Universal** | A rare pathogen class that can use every bundled mutation; it does not mean every custom addon mutation is automatically compatible. |
