## Documentation status

The source and bundled JSON resources are the authority for the current test build. Pages under `Test Version` and `Research` describe the newest implementation. Older notes remain useful for individual tools and blocks, but a page marked with a **Current test version** section should use that section when older behavior conflicts with it.

This is test-build documentation, not a claim that every path has passed an in-game multiplayer smoke test. See [[Testing Checklist]] for the exact validation status.
