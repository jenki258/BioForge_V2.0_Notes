# Vaccine Correction Matrix

#BioForge #BioForge_V0_54T #Mechanic #VaccineMaker #Correction #Symptom #Research #PlayerGuide

The fourth Vaccine Maker page models the non-sequence half of vaccine design: clinical, transmission, mutation, ecological, and lifecycle characteristics.

## Input types

- Boolean channels display True/False.
- Enum channels display meaningful names.
- Percentage channels use 0–100 with 101 possible states.
- Large values such as colony radius, infestation capacity, infection strength, and incubation can be typed directly up to their defined bounds.

## Controls

- **Reset:** restores deterministic starting values for the inserted strain.
- **Read:** imports a matching correction template or exact-strain Medical Report. Clinical report readings fill only compatible channels.
- **Write:** records the complete matrix onto paper, CRISPR Notes, or a Book and Quill.

Mismatched strain documents are rejected. The matrix contributes to final vaccine quality but the screen does not reveal the complete hidden correct answer for free.
